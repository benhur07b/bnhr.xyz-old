# bnhr.xyz-old

The archive of the old BNHR site, built with Jekyll and published at [old.bnhr.xyz](https://old.bnhr.xyz). The current site is at [bnhr.xyz](https://bnhr.xyz).

This repository is frozen. It was copied from the last Jekyll commit of [benhur07b.github.io](https://github.com/benhur07b/benhur07b.github.io) (tag `jekyll-final`, same files; the 2019 Mapbox web-mapping tutorial was removed from the history, so commit hashes differ), with one commit on top that turns it into an archive: a banner on every page, sign-up and application forms replaced with a closed notice, the retired Universal Analytics tag removed, and links to old pages kept inside the archive. Old post and page URLs on bnhr.xyz redirect here.
